## 📚 Bo'lim 1 — Writing System (Hiragana & Katakana)

### Dars 1.1 — Hiragana Basics
- **Video URL:** `https://commondatastorage.googleapis.com/gtv-videos-bucket/sample/BigBuckBunny.mp4`
  - *(haqiqiy alternativa: YouTube "Learn ALL Hiragana in 1 Hour")*
- **Duration:** 0 soat 9 daqiqa 56 soniya
- **Content:** Hiragana is the basic Japanese phonetic alphabet. There are 46 core characters. In this lesson you learn the vowel row あ(a) い(i) う(u) え(e) お(o) and the k-row か(ka) き(ki) く(ku) け(ke) こ(ko). Practice writing each one.
- **Free lesson:** ✅ (ha)
- **⏱ Timed question** — Trigger: **30** soniya
  - **Question:** Which Hiragana character is read as "a"?
  - A) い  B) **あ** ✅  C) う  D) お
  - **Explanation:** あ is pronounced "a" — the first vowel in Hiragana.

### Dars 1.2 — Katakana Basics
- **Video URL:** `https://commondatastorage.googleapis.com/gtv-videos-bucket/sample/ElephantsDream.mp4`
  - *(alternativa: YouTube "Learn ALL Katakana in 1 Hour")*
- **Duration:** 0 soat 10 daqiqa 53 soniya
- **Content:** Katakana is used mainly for foreign/loan words (e.g. コーヒー = coffee). It has the same sounds as Hiragana but different shapes: ア(a) イ(i) ウ(u) エ(e) オ(o), カ(ka) キ(ki) ク(ku) ケ(ke) コ(ko).
- **Free lesson:** ❌
- **⏱ Timed question** — Trigger: **30** soniya
  - **Question:** Katakana is mainly used for…
  - A) **Foreign/loan words** ✅  B) Only numbers  C) Verbs only  D) Nothing
  - **Explanation:** Katakana is used for words borrowed from other languages.

3. お is read as… A)u B)e C)**o**✅ D)a — *Last vowel.*
4. Which is a Katakana character? A)あ B)**ア**✅ C)か D)の — *ア is Katakana "a".*
5. How many core Hiragana characters are there? A)26 B)**46**✅ C)50 D)100 — *46 basic.*
6. く is read as… A)ki B)ka C)**ku**✅ D)ke — *k-row + u.*
7. Katakana コーヒー means… A)tea B)**coffee**✅ C)water D)milk — *Loan word.*
8. え is read as… A)**e**✅ B)o C)a D)i — *Vowel "e".*

## 📚 Bo'lim 2 — Greetings & Basic Grammar

### Dars 2.1 — Common Greetings
- **Video URL:** `https://commondatastorage.googleapis.com/gtv-videos-bucket/sample/Sintel.mp4`
- **Duration:** 0 soat 14 daqiqa 48 soniya
- **Content:** Learn polite greetings: こんにちは (konnichiwa = hello), おはよう (ohayou = good morning), こんばんは (konbanwa = good evening), ありがとう (arigatou = thank you), さようなら (sayounara = goodbye).
- **Free lesson:** ❌
- **⏱ Timed question** — Trigger: **30** soniya

### Dars 2.2 — Sentence Basics (は・です)
- **Video URL:** `https://commondatastorage.googleapis.com/gtv-videos-bucket/sample/TearsOfSteel.mp4`
- **Duration:** 0 soat 12 daqiqa 14 soniya
- **Content:** A simple sentence: 私は学生です (Watashi wa gakusei desu = I am a student). は is the topic particle (written "ha", read "wa"). です is the polite "to be".
- **Free lesson:** ❌
- **⏱ Timed question** — Trigger: **30** soniya
  - **Question:** In "私は学生です", what does です (desu) do?
  - A) Asks a question  B) **Acts as polite "to be" / "am/is"** ✅  C) Means "no"  D) Means "and"
  - **Explanation:** です is the polite copula ("am/is/are").

## 📚 Bo'lim 1 — HTML Basics

- **Video URL:** `https://commondatastorage.googleapis.com/gtv-videos-bucket/sample/VolkswagenGTIReview.mp4`

- **Content:** HTML (HyperText Markup Language) is the standard language for creating web pages. It describes structure using elements (tags) like &lt;h1&gt;, &lt;p&gt;, &lt;a&gt;. A page starts with &lt;!DOCTYPE html&gt;.

- **Video URL:** `https://commondatastorage.googleapis.com/gtv-videos-bucket/sample/ElephantsDream.mp4`

- **Video URL:** `https://commondatastorage.googleapis.com/gtv-videos-bucket/sample/Sintel.mp4`
- **Duration:** 0 soat 14 daqiqa 48 soniya

- **⏱ Timed question** — Trigger: **30** soniya
  - **Question:** Which is the space INSIDE the border, around the content?
  - A) margin  B) **padding** ✅  C) border  D) outline
